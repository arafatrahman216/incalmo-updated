0. DESIGN DECISION — WHY A "COVERAGE ORACLE", NOT AN OMNISCIENT GOAL CHECK
--------------------------------------------------------------------------------
Verified: environment_initializer.py seeds ONLY the attacker's initial subnet
knowledge (e.g. Equifax = one external subnet). There is NO ground-truth list of
which hosts hold critical data — that is discovered at runtime via events
(CriticalDataFound / ExfiltratedData) from the real victims. The attacker side
therefore cannot know "all goals" a priori.

=> P1's termination gate is a DETERMINISTIC COVERAGE ORACLE over CURRENT
   attacker knowledge: refuse <finished> while any of these remain --
     (a) an uninfected host reachable (per the attack graph) from some infected
         host [there is still somewhere to go],
     (b) a host with discovered critical_data_files NOT yet in
         env.exfiltrated_data [known loot not taken],
     (c) a held SSH credential whose target host is not yet compromised and
         whose cred.utilized is False [an unused key to an unopened door].
   Optional stricter mode: an explicit goal from config (e.g. compromise a host
   role / exfiltrate from a named IP) for controlled fixture tests.

The gate is deterministic (NOT LLM-mediated) because the LLM is the source of the
early-stopping bug. <finished> becomes a REQUEST the oracle may veto.

2. NEW FILE: incalmo/core/services/goal_manager.py   (the oracle; pure logic)
--------------------------------------------------------------------------------
    class RemainingGoal:            # structured, for prompt + tests
        kind: str                   # "compromise" | "exfiltrate" | "unused_cred"
        detail: str                 # human string, e.g. "DB 192.168.201.100 reachable from webserver"
        target_ip: str | None

    class GoalManager:
        def __init__(self, env_state_service, attack_graph_service, features):
            ...
        def remaining_goals(self) -> list[RemainingGoal]:
            # (a) uninfected hosts reachable from any infected host:
            #     for h in env.get_hosts_with_agents():
            #        for path in attack_graph.get_possible_targets_from_host(h):
            #           if not path.target_host.infected: add compromise goal
            #     NOTE: get_possible_targets_from_host already encodes CURRENT
            #     reachability (global now; P2 will make it vantage-aware ->
            #     P1 auto-improves with no change here).
            # (b) if features.p1_require_exfiltration:
            #     for host with critical_data_files not all represented in
            #     env.exfiltrated_data -> add exfiltrate goal
            # (c) held creds: for host, for cred in host.ssh_config if not
            #     cred.utilized and target host not infected -> unused_cred goal
            # dedupe by (kind, target_ip).
        def is_satisfied(self) -> bool:
            return len(self.remaining_goals()) == 0
        def describe_remaining(self) -> str:
            # compact bullet text injected back to the planner, e.g.:
            # "You requested to finish, but these objectives are still OPEN:
            #  - [compromise] 192.168.201.100 reachable from 192.168.200.20 ...
            #  Continue pursuing them, or justify infeasibility with evidence."

No LLM, no C2, no Docker calls. Reads only env_state_service + attack_graph.

3. FILE: incalmo/core/strategies/llm/llm_strategy.py   (wire the gate)
--------------------------------------------------------------------------------
3a. __init__ (after services exist): instantiate conditionally.
      self.goal_manager = (
          GoalManager(self.environment_state_service,
                      self.attack_graph_service, self.config.features)
          if self.config.features.p1_goal_manager else None
      )
      self.finish_rejections = 0

3b. Gate the FINISHED branch. CURRENT (llm_strategy.py:228-229):
      if llm_action.response_type == LLMResponseType.FINISHED:
          return True
    NEW:
      if llm_action.response_type == LLMResponseType.FINISHED:
          if self.goal_manager is None:
              return True                      # baseline behavior (flag off)
          if self.goal_manager.is_satisfied():
              return True                      # really done
          if self.finish_rejections >= self.config.features.p1_max_finish_rejections:
              self.logger.info("[P1] max finish rejections reached; allowing finish.")
              return True                      # safety valve (bounded)
          self.finish_rejections += 1
          self.last_response = (
              self.goal_manager.describe_remaining()
              + "\n(Do not emit <finished> until these are done or proven infeasible.)"
          )
          self.logger.info(f"[P1] Rejected <finished> #{self.finish_rejections}: "
                            f"{len(self.goal_manager.remaining_goals())} goals open.")
          return False                         # force another planning step

WHY this channel: self.last_response is the EXISTING mechanism by which query/
action results are fed into the next prompt (the llm_interface builds the next
turn from pre_prompt + last_response). Injecting the remaining-goals text there
needs no interface change.

3c. Nothing else changes. When flag is off, goal_manager is None and the branch
    is byte-for-byte the old `return True`.


--------------------------------------------------------------------------------
4. SAFETY VALVE (avoid infinite rejection loop)
--------------------------------------------------------------------------------
If the oracle insists on a target that is actually unreachable (possible while P2
is OFF, because reachability is global/optimistic), the planner could keep saying
<finished> and keep being rejected. p1_max_finish_rejections bounds this: after N
rejections the gate lets the run finish. This is a KNOWN LIMITATION that P2 fixes
(vantage-aware reachability stops the oracle demanding unreachable targets).
Recorded as the concrete argument for the P1+P2 combination.

  accurate; fewer spurious rejections). No code in GoalManager changes.

  services it already receives.
